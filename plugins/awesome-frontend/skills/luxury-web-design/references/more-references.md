# More Luxury References (measured)

Three more refined sites, captured live (tokens + screenshots). Anchor: aesop.com
(quiet luxury). These show the two luxury registers: **stark quiet-luxury** and
**warm atmospheric craft**.

## The Row — `therow.com` (stark quiet luxury) · `therow.png`
- Tokens: bg `#FFFFFF`, text `#000`, accent black; font **Basic Commercial** (a
  quiet neo-grotesque); `radius: 0`; H1 ~13px (tiny).
- Read: the definitive "quiet luxury" site. Almost nothing on screen: a tiny
  centered wordmark, vast white space, minuscule refined type, full-bleed calm
  imagery. Extreme restraint = the signal of expense. No accent, no ornament —
  confidence through near-emptiness.

## Le Labo — `lelabofragrances.com` (warm atmospheric craft) · `lelabo.png`
- Tokens: bg `#F6F8F6` (warm off-white), text `#333`, accent **wine `#B63547`**;
  font **Bell Gothic** (utilitarian gothic) + Helvetica; `radius: 0`.
- Read: apothecary luxury — a moody, dark, full-bleed photograph of a craft
  workshop (vials, aged wood), a tiny utilitarian wordmark, a quiet location-
  selector. Luxury via **atmosphere, materials, and craft**, not gloss. Warm,
  muted, hand-made feeling; type stays small and unfussy.

## Hermès — `hermes.com` (classic luxury) · `hermes.png`
- Tokens: bg **cream `#FCF7F1`**, text `#000`, accent slate `#2B333F`; font **Gill
  Sans** + Manrope; `radius: 0`; H1 ~12px (tiny).
- Read: heritage luxury — warm cream canvas, refined humanist type set very small,
  generous space, full-bleed editorial imagery, slow pacing. Classic, calm,
  precise. Confirms: even the loudest luxury brand whispers on the web.

## The transferable lesson
Two registers, same restraint: **stark** (white, near-empty, tiny type — The Row)
or **warm/atmospheric** (cream/muted canvas, craft imagery, one quiet accent —
Le Labo, Hermès, Aesop). Always: refined type set *small*, vast calm space, slow
soft motion, impeccable alignment. Luxury is what you leave out.

# More Swiss / Minimal References (measured)

Three more grid-driven, type-led sites, captured live (tokens + screenshots).
Anchor: swissted.com (see case study). Notably, modern Swiss often keeps the rigor
but swaps Helvetica for a contemporary grotesque and adds ONE electric accent.

## Grilli Type — `grillitype.com` · `grillitype.png`
- Tokens: bg `#FFFFFF`, text `#000`, accent **electric green `#30FF00`**; fonts
  **GT Mechanik / GT Corporate** (their own grotesques); `radius: 0`; H1 ~16px.
- Read: a Swiss type foundry — the modern International Typographic Style. A tight
  visible grid, a single neutral grotesque used at small, precise sizes (type *is*
  the content), black-on-white, one loud accent. Hierarchy from scale + position,
  not ornament.

## Lineto — `lineto.com` · `lineto.png`
- Tokens: text `#000` on light; font **Unica77/Unica** (LL Unica — a Haas-Unica
  Swiss grotesque revival); minimal chrome.
- Read: the classic Swiss foundry. Austere, list-like, utilitarian — a catalog of
  typefaces presented with near-zero styling. The reference for "the grid and the
  grotesque do everything." Restraint as authority.

## Edenspiekermann — `edenspiekermann.com` · `edenspiekermann.png`
- Tokens: bg `#FFFFFF`, text `#000`, accent **red `#FB263B`**; fonts **FF Meta /
  FF Real** (Spiekermann's own); H1 small.
- Read: Erik Spiekermann's studio — rigorous grid systems with a single red accent
  and a precise, legible type system. Proof that Swiss = an *information-design*
  mindset (clarity, hierarchy, system), not just a Helvetica skin.

## The transferable lesson
Pick **one neutral grotesque**, show the **grid** in alignment, set type **small
and precise**, use **one decisive accent** (red, electric green…), keep
`radius: 0`, and let scale/weight/position carry hierarchy. Nothing decorative.
